# Security policy

Please **do not open a public issue** for a vulnerability.

Report it privately through GitHub: **Security → Report a vulnerability**
(GitHub Security Advisories) on this repository. Include the affected version,
a description, and a reproduction if you have one. We will acknowledge the
report, keep you informed, and credit you in the advisory unless you prefer
otherwise.

Only the latest released minor version receives security fixes while the SDK
is in `0.x`.
